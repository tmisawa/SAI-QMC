Conclusion

Performance target confirmed. 16x16 U=4 beta=16 on kugui i2cpu gives serial 1.240x speedup at stab=4 and 1.219x at stab=8. MPI np16 smoke gives 1.232x / 1.228x.

In every alternating profile, measurement-phase green_stack_build calls dropped to zero. This is the intended steady-state behavior after the even warmup (nwarm=4) has created the carried suffix stack.

Drift smoke did not fail, but the pre-stabilization wrapped-G drift is larger in alternating mode, especially beta=16/stab=8 (max_inf=1.47 vs 0.083 for forward). This is not a fail-fast event and all rows keep sign=1, dN=0, but it argues for keeping alternating opt-in and monitoring drift in longer production validation before changing defaults.

Decision

  • Task 5 performance acceptance is satisfied: stack build is removed from steady-state measurement and sweep speedup is about 1.22-1.24x.
  • MPI smoke confirms the same behavior at np16 on the same i2cpu node.
  • Do not make alternating the default yet. Keep it opt-in until longer production statistics and drift monitoring are recorded, especially for stab=8.
