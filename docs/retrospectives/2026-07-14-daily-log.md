## 今日の重要な判断

- 問題は determinant そのものではなく、長い行列積の scale separation による
  `l->D[i] * (l->T * r->U)[i,j] * r->D[j]` の overflow。
- global-offset log-combine は first fix として不適切。
  scale spread が dense representable width を超えるため、overflow を rank loss に
  置き換えるだけになる可能性が高い。
- two-sided Db/Ds Green reconstruction は boundary combine overflow を避ける
  有効な opt-in intermediate step。
- beta=33.325 completion は two-sided 単独の acceptance gate ではない。
  Phase 2.1 と Phase 4 review により single-factor D range overflow が残ることを確認。
- 次の本丸は Phase 6: single-factor scale countermeasure。
  第一候補は bounded multi-factor prefix/suffix storage。
