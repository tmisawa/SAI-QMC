結論

  • 16x16 U=4 では stab=8 が有力候補。 beta=16 の sweep は 1.503 -> 1.105 s/sweep、1.36x。 beta=4/8 でも約 1.38x。
  • stab=16 は不採用。 速いが drift が beta=16 で 7.0、U=12 stress で NaN も発生。
  • global default はまだ変えない。 U=12 stress は stab=4/8 でも wrapped G drift が大きい。 stab=8 は当面、16x16 U=4 production candidate として扱う。
  • 次の alternating sweep 実装は、decision gate どおり stab=4 と stab=8 の両方で測る。

Validation

PBS 内で make test と make test_slow は通過。 profile 実行と drift 診断実行は分離したため、表の sweep 時間は追加 scratch rebuild で汚れていない。PH half filling の sign=1 と dN=0 は sanity として確認されるが、stab 健全性の判定には使わない。

U=12 では stab=8 も安全な一般 default としては扱えない。 ただし今回の短い統計では stab=2/4/8 の観測量は概ね誤差内で、 stab=16 だけが NaN または明確な観測量 drift を示した。

交互スイープ実装後の追加 drift 診断でも、U=12/stab=4 では max ~50-160, mean ~1e-3 級の wrap drift が見えた。 forward の方がむしろ大きく（163 vs 50）、これは交互スイープの 退行ではなく既存の強結合 wrap drift である。したがって強結合条件では stab=2 参照と drift 残差を decision gate に使う、という本 scan の 判定方針を維持する。

Decision Gate

  • stab=8: 16x16 U=4 candidate として維持。alternating sweep は stab=4 と stab=8 の両方で測る。
  • stab=16: scan data point として残すが採用候補から外す。
  • U=12 stress の drift が大きいため、production default は変更しない。
